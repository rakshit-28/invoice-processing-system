# Invoice Processing System

A full-stack invoice management application built with React, Spring Boot, and MySQL.

## Features
- Create and manage invoices
- View invoice records in a dashboard
- Track total invoice value and pending invoices
- Store invoice data in MySQL
- REST APIs built with Spring Boot

## Tech Stack
- **Frontend:** React, JavaScript, Vite
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** MySQL
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Architecture
React frontend → Spring Boot REST API → MySQL database

## Current Status
Implemented invoice creation, invoice listing, and dashboard summary metrics.

## Future Improvements
- Invoice PDF upload and data extraction using Gemini AI
- Invoice validation and approval workflow
- Authentication and role-based access control
- Automated tests and deployment

## Setup
Configure your MySQL connection using environment variables, start the Spring Boot backend, then install frontend dependencies with `npm install` and start React with `npm run dev`.

See the source code and configuration files for the complete setup instructions.
